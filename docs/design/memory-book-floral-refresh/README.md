# 记忆手册：无底板像素标题与丰盛花藤

本轮采用透明背景的厚实像素字，去掉标题背后的整块黄色丝带。
新增玫瑰、杏金花、浅紫小花、花蕾、带叶脉的绿叶，以及蓝金与暖玫瑰两种大蝴蝶。
装饰可以延伸到书框之外，呈现花藤围绕手册生长的效果。

花艺为重新绘制的原生像素图：大花、小花、叶片和卷须有各自细节，
不是放大上一版的轻量角饰。颜色延续深棕轮廓、暖纸色和蜂蜜金，
用暖玫瑰与浅紫增加层次。

## 图集与接口

图集 `LivingNPCs/assets/ui/memory-book.png` 扩为 **256 × 512**。
原框、普通图标、封蜡约定笺和红绳约定结的坐标与像素保留；上一版小角饰和丝带
作为历史素材留在图集中，当前菜单改用新的透明标题和花藤。

| API | 源矩形 (x, y, w, h) | 建议显示尺寸 |
| --- | --- | --- |
| `TitleChineseSource` | (0, 192, 104, 28) | 416 × 112；较低视口为 312 × 84 |
| `TitleEnglishSource` | (0, 224, 176, 28) | 528 × 84；紧凑视口为 352 × 56 |
| `FloralCornerSource` | (0, 256, 96, 96) | 192 × 192 |
| `HangingVineSource` | (96, 256, 40, 112) | 80 × 224 |
| `FlowerSpraySource` | (144, 256, 64, 48) | 128 × 96 |
| `ButterflyLargeSource` | (208, 256, 40, 32) | 80 × 64 |
| `ButterflyWarmSource` | (208, 288, 40, 32) | 80 × 64 |

大角饰用于主角落；垂藤、独立花簇与两色蝴蝶负责次要位置，避免每个角落都机械
重复同一束花。菜单应保护纸页正文、头像和关闭按钮，装饰优先向皮革外侧延伸。
图集全部使用原生整数像素；显示时用最近邻和整数倍缩放。
菜单最多保持 1400 × 820 的书体，在较小窗口为框外装饰预留水平 96px、垂直 80px
的总边距；更窄或更矮的窗口会减小装饰倍数。蝴蝶避让关闭按钮，页框遮住朝向正文的藤叶。

## 可重建原稿

标题像素图分别保存在 `title-zh.json`（104 × 28）和 `title-en.json`（176 × 28）中，
与已采用的封蜡约定笺一样使用 `width`、`height`、`palette`、`rows` 格式。
背景透明，不在 JSON 或菜单中添加黄色底板。

花朵、叶片、花蕾、卷须和蝶翅轮廓保存在 `tools/generate_memory_book_ui.py` 的
独立生成函数中。生成器直接读取标题与封蜡 JSON，不依赖系统字体或网络素材。

```powershell
python tools/generate_memory_book_ui.py
```

需要 Python 和 Pillow。用户截图、从游戏导出的字体及放大预览只放在本地可视化
输出目录，不随仓库或模组分发。
